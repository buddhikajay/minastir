MINASTIR brand kit · v1.0 · November 2026

Minastir-Brand-Guidelines.pdf  The brand guidelines: idea, logo, colour, type, interface, product view, voice, campaigns.
Logos/Mark                     The Facet mark: two-tone for dark and for light grounds, plus one-colour black and white. SVG + PNG.
Logos/Lockup                   Mark + MINASTIR wordmark, four colourways. SVG + PNG (2400px wide).
Logos/Wordmark                 MINASTIR alone, outlined (no font needed). SVG + PNG.
Logos/App icon                 1024, 512, 180px PNG + SVG.
Logos/Favicon                  favicon.ico (16/32/48), PNGs, SVG.

Use SVG wherever possible. "for-dark" files go on dark backgrounds, "for-light" files on light ones.
Fonts (free, Google Fonts): Michroma (wordmark only), Outfit (display), Inter (text).
